# حديقة القرآن — رحلة أبطال القرآن 🌳

نسخة مطابقة بالوظائف من موقع [quran.ghaarsa.com](https://quran.ghaarsa.com/) — تطبيق تفاعلي للأطفال
لاستماع القرآن والتدرّب على الحفظ، بنية مستقلة بالكامل (React + Vite) برسومات مولّدة خصيصًا لهذا المشروع.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173 (تطوير)
npm run build    # بناء إنتاجي + PWA (sw.js + manifest) في dist/
npm run preview  # تشغيل نسخة الإنتاج (من هنا يظهر اقتراح تثبيت التطبيق)

npm test         # 343 اختبار (Vitest): المتجر، الترحيلات، الـ API، سلامة البيانات، fuzz، ومكوّنات
npm run test:ssr # اختبار دخان: 12 شاشة تورد HTML بلا انهيار (esbuild + react-dom/server)
npm run lint     # ESLint (react-hooks + no-unused + قواعد JSX)
npm run format   # Prettier (تعديل) / npm run format:check (فحص)
```


## PWA: يعمل بدون إنترنت وقابل للتثبيت 📲

- **قابل للتثبيت**: `manifest.webmanifest` عربي RTL مع أيقونات (192/512/maskable) — يظهر شريط «حمّل حديقة القرآن على جهازك» عند التثبيت.
- **أوفلاين**: جزء عمّ (٧٨–١١٤، ٥٦٤ آية) مدمج في `src/juz30.js` — جسر المعاني وكلماتي وآية اليوم والنصوص كلها تشتغل بدون نت؛ التلاوة الصوتية تظهر معها تنبيه «📴 التلاوة تحتاج إنترنت».
- **كاش runtime**: استجابات `api.alquran.cloud` (60) وملفات التلاوة من `cdn.islamic.network` (200) تبقى محمية (CacheFirst) — السور اللي اتسمعت قبل كده تنسمع أوفلاين.
- **كاش متواصل**: نفس الاستجابات بتتخزن في IndexedDB بمفاتيح مُرقّمة (`v1:surah:…`) — إعادة فتح التطبيق ما تعيدش جلب ما اتخزن، مع تحديث صامت في الخلفية (stale-while-revalidate).

### إضافات المرحلة الحالية (P1)

- **مشغل الحفظ**: تكرار الآية 1×/2×/4× ثم انتقال، سرعة التلاوة 0.75×/1×/1.25×، أزرار الآية التالية/السابقة — التفضيلات بتتحفظ لكل طفل.
- **سلسلة النشاط 🔥**: أي فعل هادف (كلمة جديدة، استماع، سقي ورد، آية اليوم) يدخل في سلسلة الأيام المتتالية، تظهر في كارت الطفل والحديقة والخريطة وجدار الأوسمة.
- **استرجاع عائلية ذكي**: لما يكون في تقدم مختلف على الجهازين، يظهر لكل طفل «احتفظ بهذا الجهاز / خذ من الرابط / ادمج الاثنين» — الدمج ياخد الأفضل (أكبر نجوم، كل الأوسمة والكلمات، أعلى سماع لكل سورة) وبيختبر آليًا.

### إضافات اللمسات (P2)

- **شاشة بداية** «جاري تحميل حديقة القرآن...» بتنطفي أول ما التطبيق يرسُم.
- **اهتزاز** خفيف على الصح/الغلط (موبايل، بيتحكم بيه نفس مفتاح الصوت) + **اختصارات كيبورد** في المشغل: مسافة = تشغيل/إيقاف، ←/→ = الآية السابقة/التالية.
- **حجم ووضوح الآية**: لكل طفل حجم (صغير/متوسط/كبير) + خيار «خط واضح» بدون تشكيل — بيطبق على المشغل والجسر وآية اليوم وكلماتي مع معاينة في الإعدادات.
- **شريط آيات قابل للسكرول** للسور الطويلة، بيحرك نفسه على الآية الحالية.
- **حيوية الحديقة**: البطل بيمشي للداخل أول ما تدخل، فراشتين بتطير، وشمس/قمر بوقت اليوم.
- **خطوط محلية**: Cairo وAmiri مضغوطين ومضيوين في `/fonts` — مفيش أي اعتماد على Google Fonts (الستايل شغال أوفلاين).
- **وصولية**: أزرار بأسماء شاشة (aria-label)، حلق تركيز واضحة، واحترام `prefers-reduced-motion`.
- **تصحيح تظليل الكلمة** في جسر المعاني (كان المظلوم بيتاخدها كلمة غلط) + مراجعة صياغة كل النصوص.

### إضافات العالم المرسوم (P3)

- **سلمان** هو البطل الافتراضي — واللي عندك «عمر» محفوظ من قبل بيتحول تلقائيًا لمرة واحدة (بدون فقدان أي تقدم).
- **خلفيات مرسومة** (watercolor) لكل الشاشات: الرئيسية، الجسر، كلماتي، الأوسمة، الإعدادات، وخريطة الرحلة — كلها بنفس الباليتة (تركوازي/نعناعي) بميزانية ~1.35 MB.
- **شخصية لكل رحلة**: ألوان + قصاصات احتفال مختلفة للرحلات الأربعة (وادي البدايات، بستان الفراشات، شلال الرفق، حديقة الفوانيس).
- **لحظات الحديقة**: مساء/ليل حقيقيين حسب وقت اليوم (تظليل + نجوم تلمع) + بارالاكس خفيف مع حركة المؤشر.
- **تعابير سلمان**: ضابط فرح في شاشات الاحتفال + واقف قدام الهدية في مودال الهدايا.
- **حركات صغيرة**: نجمة بتطير لعدّاد النجوم عند كل إجابة صح، دخول متدرج للبطاقات، وسام «جديد!» بتوهج أول 24 ساعة، وحلقة مستوى حول صورة الطفل.
- **حالات فاضية ودّية** بدل الفراغات (المراجعة قبل أول كلمة، مجموعة كلماتي، وتلميح زينة الحديقة).
- **خط عرض** Lalezar للشعار والعناوين + شعار موحّد 🌳 + أرقام العُدّادات tabular.

### تعضيد الهندسة (P4)

- **اختبارات Vitest حقيقية في المستودع** (`tests/`): منطق المتجر (128 claim)، سلسلة ترحيلات المخطط، عميل الـ API (مهلة/إعادة محاولة/الكاش المتواصل)، سلامة بيانات الجسر (لو data.js انفصلت عن juz30.js الاختبار بيقع فورًا)، fuzz على التطهير (260 مدخل شرير)، واختبارات مكوّنات: قواعد كشف الإجابة في Quiz، تدفق الصح/الغلط/المساعدة في StepScreen، والتكرار/الانتقال في المشغل (بـ Audio وهمي). الاختبارات طبطبت أخطاء حقيقية: كان الاختيار الصحيح بيتلوّن غلط، و`sanitizeChild` كان ممكن يرمي على مدخل ملوّث prototype.
- **CI** (`.github/workflows/ci.yml`): lint → format → tests → SSR → build على كل PR.
- **ESLint + Prettier**: react-hooks + no-unused + قواعد JSX، وصياغة موحدة (RTL-safe) — `npm run lint` صفر أخطاء.
- **عميل API معضّد**: fetch بمهلة 10 ثوانٍ (AbortController) + إعادة محاولة واحدة مع backoff (الأخطاء 4xx ما تتعادش).
- **ترحيل المخطط (migrations)**: `SCHEMA_VERSION` + سلسلة `migrateState()` — النسخ القديمة (روابط/تخزين قديم) بتترقّى آمنة، والنسخ المستقبلية المعرفه بتعدي كما هي. الترحيلات شاملة عمر→سلمان وتحويل الأوسمة لصيغة كائن.

### المراحل التوسعية (P5)

- **الجولة الثانية من جسر المعاني**: ١٠ كلمات جديدة (عَلَقٍ، كَبَدٍ، وَجُوهٌ، ٱلْفَوْزُ، مُخْلِصِينَ، يَغْشَى، ٱلثَّاقِبُ، ٱلْفَجْرِ، يَسْعَى، ٱلْحُطَمَةُ) في رحلتين (مغامرة الخلق 🌌، سماء وفجر 🌅) — كلها متحقق منها آليًا ضد النص العثماني المدمج، وبتتفتح بعد إتمام ٢٠ كلمة الجولة الأولى. أوسمة جديدة: وسام الخالق الصغير، وسام آفاق السماء، وبطل الجولتين 🏆.
- **إحصائيات الاستماع**: الوقت (دقائق) الإجمالي والأسبوعي، لكل سورة، وخط بياني لآخر ٨ أسابيع على كانفس صغير في شاشة البوابة — بيتحدّث تلقائيًا مع كل آية بتخلص (تقدير من عدد الكلمات ÷ السرعة).

### الإثراء البصري الثاني (P6) — الموجات 1–5 شغالة 🎨

> الخطة الكاملة في `PLAN.md` (قسم P6): ٢٧ أصلًا مرسومًا بالمائية في نفس الستايل المقفول (~١.٤ MB).

- **مشهد لكل رحلة** (١٠ صور): كارت كل رحلة بقى له صورة مصغرة مرسومة مكان الإيموجي، وشاشة الخطوة بدأت بلافتة مشهد كاملة باسم الرحلة — والرحلات المقفولة بتظهر رمادية مع 🔒.
- **لافتات البوابات** (٣ صور): قوس خشب بالكروم لجزء تبارك، وقوس حجر هادي لجزء قد سمع، وقوس ورد مفتوح لجزء عمّ — في شاشة الدخول وفي رأس قائمة السور.
- **رسومات بطاقات التأمل** (٤ صور): الطيور والسماوات والماء والمصابيح — بطاقة الأسبوع بتبدل رسمتها مع كل أسبوع.
- **إطار وسام مائي + كأس الأبطال**: كل وسام متحصل عليه قعد جوه إطار وردية مرسوم (الجدار ومودالات الاحتفال)، وكأس ذهبي بيلمع في احتفالات الرحلات المكتملة ووسام «بطل الجولتين».
- **زينة الحديقة المرسومة** (٨ قطع شفافة): القطة والعصفور والتنين والتاج وطوق النور والنجمة والميدالية والفراشة بقوا رسومات مائية نضيفة مكان الإيموجي الطاير — بنفس فقاعة الكلام والحركة.
- **قادم (الموجة 6 — backlog)**: لمسات كلماتي وبطاقة المشاركة وخلفية حديقة ليلية.

### الرحلة بترتيب الحفظ + كلمات تبارك وقد سمع (P8)

- **ترتيب الرحلة**: خريطة رحلة حفظ القرآن والبوابات بتبدأ بجزء **عمّ** (٧٨–١١٤) ثم **تبارك** (٦٧–٧٧) ثم **قد سمع** (٥٨–٦٦) — ترتيب الحفظ الطبيعي للأطفال.
- **٢٠ كلمة جديدة بنفس النمط**: الجولة الثالثة «جزء تبارك» (تاج المُلك 👑، دروب الوحي 🕊️) والجولة الرابعة «جزء قد سمع» (ميزان الحشر ⚖️، أسرار الأسفار 📚) — كل جولة بتتفتح بعد إتمام اللي قبلها، بأوسمة رحلات جديدة + وسام «بطل ثلاثة أجزاء» 🎖️ عند الكلمة الخمسين.
- **نص جزء ٢٨–٢٩ مدمج (٥٦٨ آية)**: `juz28-29.js` بنفس طبعة `juz30.js` (تم التحقق آليًا: مطابقة حرفية ٥٦٤/٥٦٤ لسور الجزء الثلاثين) — كلمات الجسر وتفاصيل كلماتي بتشتغل بدون إنترنت لكل الأجزاء الثلاثة.
- **٤ مشاهد مرسومة** للرحلات الجديدة بنفس الستايل المائي (تاج، دروب وحي، ميزان، أسفار).

### بوابة جزء عمّ (P7) — أضيفت بعد ملاحظة مستخدم 🌸

- **الفجوة**: بوابات الاستماع كانت جزء تبارك وقد سمع بس (٥٨–٧٧) — جزء عمّ كان موجودًا كنص (الجسر، كلماتي، آية اليوم) لكن **بدون بوابة استماع ولا مكان على خريطة الرحلة**.
- **الإضافة**: بوابة ثالثة «بوابة جزء عمّ» (النبأ→الناس، ٣٧ سورة) بنفس محرك البوابات، مع لافتة مرسومة (قوس الورد). خريطة الرحلة بقت ٥٨–١١٤ كاملة (٥٧ سورة، ١١٣٢ آية) والانتقال السريع بيلقي أي سورة من جزء عمّ.
- **أوفلاين**: نص جزء عمّ متدمج أصلًا — القائمة والنص بيشتغلوا بدون نت، والتلاوة الصوتية محتاجة اتصال كالمعتاد.
- **اختبارات جديدة**: البوابات متصلة ٥٨–١١٤ بدون فجوات، و`SURAH_META` لجزء عمّ بتتاشتق من النص المدمج نفسه (مستحيل يختلفوا).
- **بطاقة تقدم قابلة للمشاركة**: زر «📸 شارك بطاقتك» في جدار الأوسمة بيرسم PNG (٦٠٠×٧٦٠) من الكانفس — الاسم، الصورة، النجوم، الأوسمة، الكلمات، السلسلة، دقائق الاستماع — وبيتشاركها على الواتساب (navigator.share) أو بتنزّل صورة.
- **بطاقات تأمل أسبوعية**: ٤ تأملات من سورة الملك (الطيور، السماوات، الماء، المصابيح) بتتبدّل كل أسبوع بشكل ثابت (ISO week) — نفس التلاوة الصوتية.
- **وضع الوالدين**: رمز PIN (٤ أرقام) يقفل عليه التقييد: حدّ يومي للاستماع (١٥–١٢٠ دقيقة أو بدون حد) + ساعات سكون (بتفهم التجاوز منتصف الليل). لما يبقى وقت سكون أو يخلص الحد، المشغل بيقفل بوجه ودود 🔒، وفي لافتة تلميح في قائمة السور. كل التقييد محفوظ كـ «وضع الوالدين» في الإعدادات.
- **قارئ الافتراضي**: «مع الأطفال» (الحسين العزازي) بقى هو التلاوة الافتراضية عند أول تشغيل — أسهل على الصغير.
- **المخطط v3**: ترحيل جديد يضيف `stats` و`parent` لكل طفل قديم آمنة — نفس سلسلة P4 (والاتجاه: النسخ أعلى من الحالية بتعدي كما هي). الاختبارات طبطبت أخطاء حقيقية: دالة بحث الكلمات في الجسر كانت بتدور في الجولة الأولى بس (كلمات الجولة الثانية كانت بتضيع)، والتطهير كان بيحذفها عند إعادة التحميل.

## التقنيات والمصادر

- **React 18 + Vite 5** — بدون أي مكتبات UI خارجية، CSS خالص.
- **النصوص والتلاوات**: [api.alquran.cloud](https://alquran.cloud) (نص عثماني + تلاوات لكل آية من ٤٥+ قارئًا).
- **التخزين**: `localStorage` في المتصفح. الصور لا تُرفع لأي خادم.
- **المزامنة**: «مفتاح حديقة أسرتك» رابط يحمل البيانات في الـ hash — افتحه على أي جهاز تفتح الحديقة هناك (بدون خادم).
- **الصوتيات**: مؤثرات واجهة خفيفة مولّدة بـ WebAudio.
- **المعاني**: كتابات مبسطة بأسلوب التطبيق بالاعتماد على فهم التفسير الميسّر، مع رابط المصدر لكل آية.
- **الرسومات**: مولّدة بالذكاء الاصطناعي خصيصًا لهذا المشروع (خلفية الحديقة، الشخصية، الهدية) ومهذبة بخلفية شفافة.
