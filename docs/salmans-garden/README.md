# حديقة سلمان — فهرس الوثائق


## موقع واحد: الحدائق الأربع

صفحة واحدة (`index.html`) فيها كل شيء، مع شريط سفلي ثابت للتنقّل: الغابة · الحروف · الأرقام · القرآن · English.
زر الرجوع في الهاتف والمتصفح يرجع خطوة داخل الغابة، ولكل شاشة رابط مباشر:

| الرابط | الشاشة |
|---|---|
| `/#/` | الغابة: زيارة اليوم والحدائق الأربع والأوسمة وولي الأمر |
| `/#/arabic` | حديقة الحروف: خريطة الحديقة بـ ٧ محطات (مستويات «مغامرة الحروف») |
| `/#/arabic/3` | محطة: لعبة «صِل الحرف بصديقه» لحروفها الأربعة + بطاقات الحروف |
| `/#/arabic/3/play` | اللعبة نفسها |
| `/#/arabic/letter/ب` | صفحة الحرف وقصصه |
| `/#/math` · `/#/english` | حديقة الأرقام (٤ محطات، ١–٢٠) · حديقة الإنجليزية (٤ مجموعات أصوات) |
| `/#/quran` | حديقة القرآن: خريطة واحدة (٣ مستويات بقصص، ثم بقية جزء عمّ وتبارك وقد سمع) |
| `/#/quran/surah/78` | صفحة السورة: القصة ← استمع وردّد ← حفظتها (أو خطوتان للسور بلا قصة) |
| `/#/quran/explore/words` | كنوز الرحلة: `words` · `bridge` · `daily` |

العناوين القديمة تبقى تعمل: `/salman.html` ← `/`، و`/quran.html` ← `/#/quran` (روابط استرجاع الحديقة `#garden=` تمرّ كما هي).

- لعبة الحروف: الكود في `src/huroof/` (التنسيق محصور تحت `.hp-root`)، الأصوات في `public/huroof/audio/`، ورسومات الحيوانات مشتركة من `public/salman/art/animals/`. نجوم كل محطة تُحفظ في حالة سلمان (`huroof`) وتُضاف لحديقة الحروف بقدر التحسّن فقط.
- رحلة القرآن: الكود في `src/*.jsx` كما هو، يُعرض داخل حديقة القرآن (`App` مع `embedded`) وتنسيقه محصور تحت `.qg-root`. نجوم حديقة القرآن في الغابة = قصص السور + نجوم رحلة القرآن.
- **خريطة الحديقة** (`src/salman/GardenMap.jsx`): نفس الخريطة للحدائق الأربع. كل محطة شجرة تنمو مع التقدّم (`growth-1..5.png`) ولافتة بشريط تقدّم، وكل عنصر زهرة بحلقة تقدّم. الخطة والقرار في [`PLAN-VISUAL-CONSISTENCY.md`](PLAN-VISUAL-CONSISTENCY.md).
- النشر: مشروع Vercel ‏`huroof-play` مربوط بالمستودع؛ `huroof-play/vercel.json` يبني الموقع كله من الجذر.

فهرس لكل ما يخص حديقة سلمان داخل هذا المستودع. الكود في `src/salman/`، وصفحتها هي الصفحة الرئيسية للموقع `index.html` (العنوان القديم `/salman.html` يحوّل إلى `/`).

## تشغيل وفحص

```bash
npm run dev            # ثم افتح /
npx vitest run         # كل الاختبارات (سلمان: tests/salman-*)
npx eslint src tests && npx prettier --check "src/**/*.{js,jsx}" "tests/**/*.{js,mjs,jsx}"
npm run build          # يبني index.html (الغابة) و quran.html (رحلة القرآن) ويضعهما في precache
npm run test:ssr       # دخان SSR لكل الشاشات
```

## تحقق دون إنترنت

السكربت داخل المستودع: `tools/salman-offline-check.mjs`. يفتح `/` أونلاين، وينتظر الـ service worker حتى يتحكم في الصفحة ويخزّن الملفات، ثم يقطع الشبكة ويعيد فتح التطبيق وحديقة الحروف. يتحقق من: الرئيسية، والحديقة، والمقاطع والصور والأيقونة والـ manifest من الكاش، وعدم وجود أخطاء صفحة. التشغيل ومتطلبات المتصفح في رأس الملف. آخر نتيجة: ناجحة (150 عنوانًا مخزّنًا، بلا أخطاء صفحة).

## قواعد لا تُكسر

- لا تُعدَّل ملفات حديقة القرآن (`src/App.jsx` وباقي `src/` خارج `src/salman/`، و`src/store.js`، و`PLAN.md`).
- المحتوى المولّد لا يُعدَّل يدويًا: `src/salman/data/stories.generated.js` و`journey/index.html`.
- لا توجد مؤقتات ولا لوحات متصدّرين ولا عقوبة على الخطأ.

## النسخ الاحتياطي بحساب Google (Supabase) — اختياري

- المشروع: Supabase `quran-garden` (`dsjazywixcqzwwjnhzzf`, سنغافورة). جدول واحد `public.family_progress`: صف لكل عائلة (`user_id`) فيه حالة الغابة (`salman`) وحالة رحلة القرآن (`quran`)، مع RLS: كل حساب يقرأ ويكتب صفّه فقط.
- الكود: `src/salman/lib/cloud.js` (تُحمَّل مكتبة Supabase عند الحاجة فقط) و`src/salman/CloudSync.jsx` (قسم «☁️ النسخ الاحتياطي» في وضع ولي الأمر).
- بلا دخول: كل شيء محلي وأوفلاين كما كان. بعد الدخول: أول مزامنة تأخذ النسخة الأكثر تقدّمًا، ثم رفع تلقائي بعد ٤ ثوانٍ من أي تغيير.
- المفتاح في الكود هو المفتاح العام (`sb_publishable_…`) — الحماية من RLS، ولا يوجد مفتاح خدمة في الواجهة.
- **إعداد مطلوب مرة واحدة في لوحة Supabase:** Authentication → Sign In / Providers → Google (Client ID + Secret من Google Cloud)، وAuthentication → URL Configuration: Site URL ‎`https://huroof-play.vercel.app` وإضافة نفس الرابط في Redirect URLs.
