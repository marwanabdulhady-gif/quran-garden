## 4. قواعد Leitner (مكتوبة بالتفصيل)

الحقول: `box` من 0 إلى 3، و`days` = عدد **الأيام المختلفة** اللي اتجاوب فيها صح.

1. **إجابة صح في يوم جديد** (غير آخر يوم اتسجلت فيه إجابة صح): `box = min(box + 1, 3)` و`days += 1`.
2. **إجابة صح في نفس اليوم**: مفيش ترقية (يمنع الحشو في جلسة واحدة)، وبتتسجل كـ«ممارسة».
3. **إجابة غلط**: `box = 1`، و`days` يفضل كما هو.
4. **متقنة** = `box = 3` **و** `days >= 3`. لو الصندوق 3 لكن `days < 3` تفضل «تعلّم».
5. **مواعيد المراجعة**: box 0 → نفس الجلسة، box 1 → بكرة، box 2 → بعد 3 أيام، box 3 → بعد 7 أيام.
6. **الجديد**: لا يزيد عن 2 لكل حديقة في اليوم.

مثال: حرف «ب» يتجاوب صح يومين مختلفين → box 2 (days=2) → يوم تالت صح → box 3 (days=3) = متقن.
