## Conventions
- Each chapter = one letter. Heading `## الفصل N — الحرف: X — «كلمة»`, then the story, the parent questions (أسئلة تربوية وأفكار عملية), and the source footnotes (`⁽¹⁾`).
- Hadith and Qur'an citations are kept as printed in the book. They have not been checked against external sources.
- Harakat are reproduced as shown in the scan and may differ from the printed book.

## How to finish verification
1. Proofread `alphabet-with-the-companions.md` against the printed book, chapter by chapter, and clear every `[مراجعة]` marker.
2. Re-fetch chunks 1–2 of the 1Qip source and check the draft against them.
3. Only then use these texts to write app stories (see `docs/salmans-garden/PROPOSAL.md`).
